Help

The keyboard won't show up
  1. Flip the keyboard's mode switch to wired and use the USB-C cable. The 2.4 GHz dongle and Bluetooth can't reach the screen.
  2. In the browser's pop-up, pick the AK820 / 820PRO entry (not "2.4G Dongle").
  3. Close the official AJAZZ / Epomaker driver if it's running. Only one program can talk to the screen at a time.
Linux: "Connect" fails or the keyboard isn't listed

Linux doesn't let browsers open keyboards by default. Install this rule once, then unplug and replug the keyboard:

echo 'KERNEL=="hidraw*", ATTRS{idVendor}=="0c45", ATTRS{idProduct}=="800a|8009", TAG+="uaccess"' \
  | sudo tee /etc/udev/rules.d/99-ak820.rules
sudo udevadm control --reload && sudo udevadm trigger
Limits

The screen is 128 × 128 pixels with 16-bit colour. The keyboard stores up to about 140 frames (it reports its exact limit after you connect). Sending is roughly 30 KB/s, so a full 140-frame animation takes about 2½ minutes. Keep the cable plugged in until it finishes.

Can I see what's on my keyboard right now?

Only if you sent it from here. The keyboard has no way to send its picture back, so this page keeps its own copy of everything you send (History, above). History is stored in this browser only. Clearing site data or switching browsers starts it empty. Anything you sent with the official driver isn't in it.

Is this safe?

This page only uses the same commands as the official driver to set the screen picture and clock. It never touches firmware. Everything happens in your browser, and your files never leave your computer.
